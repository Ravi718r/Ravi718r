## 💻 Featured Projects

### 1. [ResolveAI — AI Customer Support Resolution Agent](https://github.com/Ravi718r/ResolveAI)

An AI-powered customer support system designed to understand customer issues, retrieve order and payment information, execute controlled resolution workflows, and escalate complex cases to human support.

**Key features**
- Stateful AI workflows using LangGraph and LangChain.
- MCP tools for controlled backend operations.
- LLM gateway with model routing and fallback.
- FastAPI backend with PostgreSQL, SQLAlchemy, and Alembic.
- Workflows for failed payments, duplicate payments, refunds, cancellations, and missing orders.
- Authorization, human escalation, and automated testing.

**Tech stack:** Python, FastAPI, LangGraph, LangChain, MCP, PostgreSQL, SQLAlchemy, Docker, Pytest.

🔗 **[Explore ResolveAI on GitHub](https://github.com/Ravi718r/ResolveAI)**

### 2. [Production-Style RAG System](https://github.com/Ravi718r/Rag_project)

A Retrieval-Augmented Generation system focused on document retrieval, grounded answers, and measurable retrieval quality.

**Key features**
- Document ingestion, chunking, and embedding pipelines.
- ChromaDB vector search and BM25 hybrid retrieval.
- Metadata-based routing and Cross-Encoder reranking.
- RAGAS-based evaluation and synthetic test datasets.
- Experiment tracking, regression analysis, and quality gates.
- FastAPI integration and Docker-based deployment setup.

**Tech stack:** Python, FastAPI, LangChain, ChromaDB, Hugging Face, BM25, RAGAS, Docker.

🔗 **[Explore the RAG Project on GitHub](https://github.com/Ravi718r/Rag_project)**

### 3. [Student Management REST API](https://github.com/Ravi718r/student-management-api)

A backend application for managing student and academic records through structured REST APIs.

**Key features**
- Layered backend architecture.
- PostgreSQL integration with SQLAlchemy.
- Authentication, authorization, and protected endpoints.
- Database schema migrations using Alembic.
- Containerized development environment.

**Tech stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pydantic, JWT, Docker.

🔗 **[Explore the Student Management API on GitHub](https://github.com/Ravi718r/student-management-api)**
